# Система учёта посещаемости студентов

Локальное веб-приложение для учёта посещаемости, пропусков, лимитов часов и перезачётов.

## Возможности

### Для студента:
- Просмотр лимита часов и остатка
- Просмотр расписания своей группы
- Отметка присутствия/отсутствия на парах
- Просмотр перезачётов и освобождений
- История всех отметок
- Расчёт: сколько пар можно пропустить

### Для старосты:
- Просмотр всех студентов группы
- Отметка посещаемости за студентов
- Сводка по группе: кто сколько пропустил
- Отчёт: у кого лимит почти исчерпан

### Для администратора:
- Управление семестрами, группами, студентами
- Управление предметами и преподавателями
- Создание шаблонов расписания
- Генерация занятий на весь семестр
- Управление перезачётами и освобождениями
- Настройка режимов расчёта пропусков
- Резервное копирование данных

## Бизнес-правила

### Лимит пропусков
- По умолчанию: 100 часов на студента за семестр
- Можно изменить глобально или индивидуально

### Режимы учёта раннего ухода
- **full_pair** — любой уход раньше = пропуск всей пары
- **exact** — считается фактически пропущенное время
- **rounded** — фактическое время с округлением

### Перезачёты и освобождения
- По предмету (все пары предмета не обязательны)
- По периоду (все пары в диапазоне дат)
- На весь семестр
- На конкретное занятие
- Перезачтённые пары НЕ тратят лимит

### Расчёт "сколько пар можно пропустить"
Учитывается:
- Остаток часов лимита
- Фактическая длительность каждой будущей пары
- Перезачёты (такие пары не обязательны)
- Отменённые пары (не влияют на лимит)

## Запуск

Приложение работает как статический сайт (SPA). Откройте `dist/index.html` в браузере.

### Локальный сервер (для доступа с телефона по локальной сети):

```bash
# Вариант 1: Python
cd dist
python -m http.server 8000 --bind 0.0.0.0

# Вариант 2: Node.js
npx serve dist -l 8000
```

Затем откройте в браузере телефона: `http://<IP-адрес-ПК>:8000`

## Хранение данных

Данные хранятся в localStorage браузера. Для переноса используйте функцию экспорта/импорта JSON.

### Резервная копия
1. Зайдите как администратор
2. Перейдите в раздел "💾 Бэкап"
3. Нажмите "Скачать резервную копию"
4. Сохраните JSON-файл

### Восстановление
1. В разделе "💾 Бэкап" выберите файл для импорта
2. Данные будут восстановлены

## Настройки

Все настройки доступны в разделе "⚙️ Настройки" (только для администратора):

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| Лимит часов | 100 | Максимум пропусков за семестр |
| Длительность пары | 120 мин | По умолчанию, если не указано время |
| Режим ухода | full_pair | Как считать ранний уход |
| Шаг округления | 15 мин | Для режима rounded |
| Направление округления | вверх | up/down/nearest |
| Допустимое опоздание | 10 мин | Не считается опозданием |
| Уваж. причина в лимит | нет | Учитывать ли уважительные |

## Допущения

1. Данные хранятся в localStorage (один браузер = одна копия данных)
2. Пароли хранятся как plain text (локальное использование)
3. Нет серверной части — всё работает в браузере
4. Синхронизация между устройствами — через экспорт/импорт JSON
5. Расписание генерируется по шаблонам на весь семестр сразу
6. Каждая пара имеет фактическую длительность по времени начала/окончания
