# 📚 Система учёта посещаемости студентов

Локальное веб-приложение для учёта посещаемости, пропусков, лимитов часов и перезачётов. Работает полностью офлайн, данные хранятся в браузере.

## 🚀 Быстрый старт

### Вариант 1: Использование готовой сборки

1. Скачайте архив с проектом или клонируйте репозиторий
2. Откройте файл `dist/index.html` в браузере
3. Войдите под любым тестовым аккаунтом (см. ниже)

### Вариант 2: Локальный сервер (для доступа с телефона)

```bash
# Перейдите в папку dist
cd dist

# Запустите HTTP-сервер (Python 3)
python -m http.server 8000 --bind 0.0.0.0

# Или используйте Node.js
npx serve dist -l 8000
```

Затем откройте в браузере телефона: `http://<IP-адрес-вашего-ПК>:8000`

**Как узнать IP-адрес ПК:**
- **Windows:** `ipconfig` → найдите "IPv4-адрес"
- **macOS/Linux:** `ifconfig` или `ip addr` → найдите ваш IP

## 📊 Бизнес-правила

### Лимит пропусков
- **По умолчанию:** 100 часов на студента за семестр
- Можно изменить глобально в настройках
- Можно установить индивидуальный лимит для каждого студента

### Режимы учёта раннего ухода
- **full_pair** — любой уход раньше = пропуск всей пары
- **exact** — считается фактически пропущенное время
- **rounded** — фактическое время с округлением (настраивается шаг и направление)

### Перезачёты и освобождения
- **По предмету** — все пары предмета не обязательны
- **По периоду** — все пары в диапазоне дат
- **На весь семестр** — полное освобождение
- **На конкретное занятие** — единичный перезачёт

**Важно:** Перезачтённые пары НЕ тратят лимит и не считаются прогулами.

### Расчёт "сколько пар можно пропустить"
Система учитывает:
- Остаток часов лимита
- Фактическую длительность каждой будущей пары
- Перезачёты (такие пары не обязательны)
- Отменённые пары (не влияют на лимит)

Все настройки доступны в разделе "⚙️ Настройки" (только для администратора):

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| Лимит часов | 100 | Максимум пропусков за семестр |
| Длительность пары | 120 мин | По умолчанию, если не указано время |
| Режим ухода | full_pair | Как считать ранний уход |
| Шаг округления | 15 мин | Для режима rounded |
| Направление округления | вверх | up/down/nearest |
| Допустимое опоздание | 10 мин | Не считается опозданием |
| Уваж. причина в лимит | нет | Учитывать ли уважительные |

```csv

ИТ-201,Петров Пётр Петрович,80
```

### Формат CSV для групп
```csv

```

### Формат CSV для предметов
```csv
name
Математика
Физика
```

### Формат CSV для преподавателей
```csv
full_name
Сидоров А.П.
Козлова М.И.
```

### Формат CSV для шаблонов расписания
```csv
group,weekday,start_time,end_time,subject,teacher,room,date_from,date_to
ИТ-201,пн,09:00,10:30,Математика,Сидоров А.П.,301,2025-09-01,2025-12-31
ИТ-201,ср,09:00,10:30,Физика,Козлова М.И.,110,2025-09-01,2025-12-31
```

**Дни недели:** пн, вт, ср, чт, пт, сб, вс (или mon, tue, wed, thu, fri, sat, sun)

## 💾 Резервное копирование

### Создание резервной копии
1. Войдите как администратор
2. Перейдите в раздел "💾 Бэкап"
3. Нажмите "📥 Скачать полную копию (JSON)"
4. Сохраните файл в надёжном месте

### Восстановление из резервной копии
1. В разделе "💾 Бэкап" нажмите "Выберите файл"
2. Выберите ранее сохранённый JSON-файл
3. Данные будут восстановлены

### Экспорт в CSV
В разделе "💾 Бэкап" можно экспортировать отдельные таблицы в CSV:
- Студенты, группы, предметы, преподаватели
- Занятия, посещаемость, перезачёты, шаблоны

**Важно:** CSV-файлы открываются в Excel (с поддержкой кириллицы благодаря BOM).

## 🐛 Решение проблем

### Данные пропали после очистки кэша
К сожалению, данные хранятся в localStorage браузера. При очистке кэша они удаляются. **Решение:** регулярно делайте резервные копии через раздел "💾 Бэкап".

### Приложение не открывается на телефоне
- Убедитесь, что ПК и телефон в одной сети Wi-Fi
- Проверьте, что файрвол не блокирует порт 8000
- Попробуйте другой порт: `python -m http.server 8080`

### Ошибки при импорте CSV
- Проверьте формат CSV (заголовки должны совпадать)
- Убедитесь, что группы/предметы/преподаватели уже существуют
- Используйте кодировку UTF-8
